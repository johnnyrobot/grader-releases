# Grader Releases

Official signed and notarized macOS public-beta artifacts for Grader.

- Download the latest DMG from the Releases page.
- Verify SHA256SUMS before installation.
- The Tauri updater reads latest.json from the latest release.
- Student work remains on the instructor device, and Canvas posting requires explicit teacher approval.
- Citation verification is experimental during beta.

The application source repository remains private during the supervised beta. This repository contains release assets and source-build provenance only.
